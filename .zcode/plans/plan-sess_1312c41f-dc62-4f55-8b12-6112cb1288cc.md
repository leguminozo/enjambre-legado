## Perfil → Dropdown + Configuración como MODAL overlay (con limpieza de legacy)

### 1. Dropdown en el área del nombre (Sidebar)
`src/components/layout/Sidebar.tsx` — el bloque usuario (avatar + nombre + rol) pasa a ser **trigger de `DropdownMenu`** (de `@enjambre/ui`):
- Items: **Configuración** (icono Settings) → abre el modal · separador · **Cerrar sesión** (destructive)
- Logout unificado con `useAuthStore.signOut()` (conserva evento `session_revoked`) + `router.push('/login')`; se eliminan los `handleLogout` raw duplicados de `Sidebar.tsx` y `SidebarRail.tsx` (el rail conserva su botón LogOut pero con el store).

### 2. Configuración como MODAL central con opacidad (no página)
`src/views/configuracion/ConfigModal.tsx` — usa **`ImmersiveModal` de `@enjambre/ui`** (`size="xl"`, ya trae overlay con opacidad/blur sobre el fondo, focus trap y lock de scroll):
- Header: eyebrow "Configuración" + título + botón X
- Dentro: **ConfiguracionHub** — el hub unificado que **fragmenta en las 7 categorías** (Datos Personales · Seguridad · Empresas · Territorio · Nivel Guardián · Preferencias · Sistema), con tarjeta avatar + nav lateral desktop y `ResponsiveTabBar` móvil (patrón actual de PerfilView)
- `usePerfil()` se llama una vez en el hub y reparte a los fragmentos
- Estado local en Sidebar (`open/onOpenChange`) — el modal se monta junto al dropdown

### 3. Fragmentos — `src/views/configuracion/` (nuevos)
- `DatosPersonalesSection.tsx` · `SeguridadSection.tsx` · `EmpresasSection.tsx` · `TerritorioSection.tsx` · `GuardianSection.tsx` — JSX extraído de `PerfilView.tsx` sin cambios de lógica
- `PreferenciasSection` — reutiliza `views/perfil/PreferenciasTab.tsx`
- `SistemaSection.tsx` — contenido actual de `ConfiguracionView` (Salud de Integraciones, Caché & Edge, Auditoría de Seguridad)
- `ConfiguracionHub.tsx` — tabs + avatar + render de fragmento activo + banner de mensaje

### 4. Ruta `/configuracion` queda como página fallback
`ConfiguracionView.tsx` (nueva versión) = `ViewShell` + mismo `ConfiguracionHub` — así el item del sidebar, el tab del bottom nav móvil y cualquier link antiguo siguen funcionando (relabel "Sistema" → "Configuración"). La experiencia primaria es el modal del dropdown.

### 5. Legacy → se quita
- `ACCOUNT_ITEMS`: se elimina item `perfil`; `sistema` → `key: 'configuracion'`, label **"Configuración"**, mission actualizada
- `BOTTOM_NAV_KEYS` + overrides de `LiquidBottomNav.tsx`: `sistema` → `configuracion` / "Configuración"
- `app/(dashboard)/perfil/page.tsx` → `redirect('/configuracion')`
- Se eliminan `src/views/PerfilView.tsx` y `src/views/ConfiguracionView.tsx` (reemplazadas); `lazy-views.ts` → `LazyConfiguracionView` apunta a la nueva ruta
- `src/views/VendedorView.tsx` — se elimina solo si grep confirma cero referencias
- El alias "Sistema" desaparece del UI

### 6. Verificación
`pnpm --filter @enjambre/nucleo build` + `tsc --noEmit` limpios.
