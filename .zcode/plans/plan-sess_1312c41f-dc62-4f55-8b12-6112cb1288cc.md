## Módulo "Alambique" — Bitácora de destilación (admin-only) en Nucleo

Herramienta dedicada para Obrera y Zángano: registro de materia prima vegetal → destilaciones → productos envasados, entrelazada con el sistema existente (QR público de trazabilidad + venta con stock).

### 1. Migración `packages/database/supabase/migrations/1003_alambique_destilacion.sql` (nueva)

Molde de `991_registro_territorial_apicola.sql` (TEXT+CHECK, índices, trigger `updated_at` idempotente, RLS):

- **`plantas_destilacion`** — materia prima: `nombre_comun`, `nombre_cientifico`, `parte_usada` CHECK (hojas/flores/corteza/raices/semillas/frutos/otra), `estado_material` CHECK (fresco/seco/semicresco), `cantidad_kg`, `origen` (texto libre), `lat`/`lng` (GPS opcional), `fecha_recoleccion`, `observaciones`.
- **`destilaciones`** — lote de proceso: `codigo` UNIQUE (`DST-YYYY-####`, generado en BFF), `planta_id` FK → `plantas_destilacion` (ON DELETE RESTRICT), `metodo` CHECK (hidrodestilacion/arrastre_vapor), `fecha_inicio`/`fecha_fin`, `carga_kg`, `agua_l`, `duracion_min`, `temperatura_promedio`, `rendimiento_hidrolato_ml`, `rendimiento_aceite_ml`, `analisis_organoleptico` JSONB (color/olor/sabor/textura), `observaciones`, `estado` CHECK (planificada/en_proceso/finalizada/descartada), `publico` BOOL, `relato_publico`.
- **`productos_destilacion`** — envasado: `destilacion_id` FK (CASCADE), `tipo` CHECK (hidrolato/aceite_esencial/otro), `volumen_ml`, `envase`, `unidades`, `fecha_envasado`, `destino` CHECK (venta/uso_propio/regalo/investigacion), **`producto_id` FK NULL → `productos`** (entrelazado venta con stock), `precio_sugerido_clp`, `observaciones`.
- **RLS**: las 3 tablas admin-only → `FOR ALL USING (public.is_admin())` (mismo patrón 1000/1002).
- Aplicar con `db:push` y regenerar tipos con `db:typegen` (proyecto ya vinculado).

### 2. BFF Hono — `apps/nucleo/src/api/routes/alambique.ts` (nueva)

Registro en `app/api/[[...routes]]/route.ts`. Routers admin: `authMiddleware + tenantMiddleware + requireProfileRole("admin")` (patrón `admin-system.ts`), validación zod con `zValidator` (patrón `produccion.ts`):
- `GET/POST /api/alambique/plantas`, `PATCH/DELETE /api/alambique/plantas/:id`
- `GET/POST /api/alambique/destilaciones` (list con join a planta), `GET/PATCH/DELETE /:id`, `GET /api/alambique/productos-venta` (select id/nombre/stock de `productos` para el select)
- `GET/POST /api/alambique/productos`, `PATCH/DELETE /:id` (list con join destilación+planta+producto de venta)
- `GET /api/alambique/dashboard` — KPIs: total destilaciones/plantas, rendimiento promedio hidrolato y aceite, por planta
- **Público** (sin auth, patrón `lotes-publicos.ts`): `GET /api/alambique/publico/:id` con validación explícita `publico = true` + validación UUID.
